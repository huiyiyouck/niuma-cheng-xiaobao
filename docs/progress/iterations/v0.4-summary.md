## 完成内容

### A 板块 — UI 重构（6 项）
- 管理页统一频道空间视图（弃用四 Tab），子频道抽屉 + SourceCard + InlineAddSource + SubChannelManager 拖拽
- 系统日志独立顶级导航 `/logs`，不再隶属频道空间
- 自定义 Toast 系统（useToast + ToastContainer + transition-group）
- 自定义 Modal 系统（useModal + ModalContainer，Promise confirm 替代 alert/confirm）
- 浏览页 + 管理页视觉/交互按原型 `browse.html` / `admin.html` 翻新（用户浏览器视觉验证 ✅）

### B 板块 — 功能闭环（8 项）
- 频道空间完整 CRUD：PUT 重命名（含 409 唯一性）+ GET delete-preview（7 项级联统计）+ DELETE 204
- Source 解绑：DELETE `/v1/channel-sources/:id`（解绑后 Source 本体保留）
- 子频道拖拽排序：PUT `/sub-channels/reorder` + 事务回滚 + 空间归属校验
- **RSS Fetcher**：rss-parser + 游标 lastPubDate + NonRetryableError + Fetcher registry
- **告警状态机**：`alerts.status` 列 + PATCH `/alerts/:id`（active→acknowledged→resolved 422 守门）+ POST `/alerts/acknowledge-all` 幂等
- **前端写操作鉴权**：`http.ts` WRITE_METHODS 注入 `x-admin-token`
- **Admin Guard**：`/v1/admin/logs` 鉴权 + ADMIN_PROTECT_READS 可选保护读操作
- **日志路径修复**：动态正则 + 日期后缀 + 降序排序

### C 板块 — 功能增强（5 项）
- 浏览页关键词搜索（ILIKE 参数化 + 多子频道 ANY()）
- Source 删除前 affected_bindings 检查（FOR UPDATE OF cs 事务保护）
- 列表骨架屏（NewsPage skeleton-list）
- 子频道筛选 300ms 防抖（@vueuse/core useDebounceFn）
- 系统日志独立页 `/logs` 完整可用（LogViewer 组件）

### 工程量
- 后端：7 个新端点 + 3 个增强 + RSS Fetcher + Admin Guard + 日志路径修复 + 1 列迁移
- 前端：5 个新组件 + 2 个 composable + 重写 AdminPage + 改造 NewsPage/AlertList/ChannelFilter
- 新增依赖：rss-parser、@vueuse/core、sortablejs、vuedraggable
- 视觉验证 Bugfix 追加：6 个 UI/交互 bug + WS 架构对齐（commit e736980）
