## 完成内容

### A 板块 — 信息源资产化重构

- 空间 → 频道两级固定结构（含空间 CRUD + 频道 CRUD + 排序）
- 信息源库独立 Tab（表格 + 7 维筛选 + 搜索 + 分页 + AND/OR 语义）
- Source 标签体系（8 字段：类型 / 来源身份 / 展示名称 / 领域 / 角色 / 主题 / 关注级别 / 备注）
- Source 双正交状态：可用性（正常 / 待修复 / 来源异常 / 已移除）+ 运行状态（抓取中 / 已停止），「未使用」= 正常 + 已停止
- Source 创建双路径：信息源库（不自动添加）/ 空间管理（验证成功自动添加；失败保存为待修复并回流提示）
- 展示位置 m:n（同一 Source 多空间多频道，含根节点）+ 共享分发 + 单次抓取去重
- 来源身份变更历史（`source_identity_history` 表，待修复 / 来源异常状态下允许修改并触发重新验证）
- 删除规则：Source 删除保留历史新闻 + 标记「来源已移除」/ 频道删除提供迁移到根节点或全部移除（冲突阻断）/ 空间删除保留全局 Source 和历史新闻

### B 板块 — X/Twitter 共享 Stream

- 共享 Filtered Stream 长连接（所有启用 X Source 复用一条连接）
- 规则同步：30s debounced 启用/停用 → `from:{username} -is:retweet -is:reply`
- 服务重启自动恢复规则 + Stream 网络断开指数退避（1s→2s→4s ... max 60s）
- Source 级补偿抓取（24h timeline，Stream 与补偿共享去重）
- X Stream 全局告警（Bearer Token 失效 / 持续断开 / 规则同步失败）独立于 Source 告警

### C 板块 — 告警与异常

- 顶级导航告警入口 + 未处理角标
- 告警状态机：未处理 → 已确认 → 已恢复 / 已忽略 ↔ 未处理（白名单 `allowedTransitions` 422 守门）
- 24h 同源同类型告警去重窗口（更新原告警而非新建）
- 失败计数口径：每次抓取调度为单位，成功一次清零，3 次连续失败标记来源异常

### D 板块 — 业务数据重置

- 全表清空脚本（`reset-business-data.sql`，按 FK 顺序 + 事务回滚 + 保留 schema/migrations）
- 部署前 pg_dump 备份 + 表级数据量统计 + Owner 二次确认门禁
- 健康检查与 drizzle migrate 空库启动 AC 覆盖

### E 板块 — 评分方法论文档

- Product Brief 已确认（3 维度首版 + 2 维度预留 + 权重版本状态机 + LLM 输出结构 + 评分版本化）
- 本轮不落地代码

### v0.5.1 — X 信息源反向同步（Owner 当面架构反转，2026-06-07）

- 数据流方向反转：X Developer Portal 成为 X Source 唯一真理源；平台被动同步（worker 启动 + 5min 定时 + 管理页手动触发）
- X Source 平台不可新增/删除（仅 Portal 操作），只能「暂停 / 恢复」
- 暂停语义：tweet 继续入 `raw_items`，前端隐藏；恢复后历史立刻可见
- X rule.tag → 本地 `display_name` 每次覆盖，UI 不可编辑
- 后端 10 项 API 行为端到端验证全过 + 前端 UI Owner 浏览器手测通过
